# 🎂 Birthday Wish Website

A small **Birthday Surprise Website** built using **HTML, CSS, and JavaScript**.

## Features

* 🔒 PIN lock to enter the website
* 🎉 Birthday message page
* 🎈 Balloon animation
* 🖼 Birthday person photo
* 🎮 3 mini games
* 🎵 Optional birthday music

## Project Files

birthday-project/

* index.html
* birthday.jpg (photo of birthday person)
* birthday.mp3 (optional birthday music)

## Setup

1. Place the **birthday person's photo** in the project folder.
2. Rename the image to **birthday.jpg** or update the image name in `index.html`.
3. (Optional) Add a music file named **birthday.mp3**.
4. Open **index.html** in your browser.

## PIN

Default PIN: **1603**
You can change the PIN inside the JavaScript `checkPin()` function.

You can edit:
